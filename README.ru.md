# Схемы Xray gRPC

Схемы Protobuf и PHP-клиенты для снимка API Xray-core. Это интеграционный слой, а не готовый сервер Xray и не обещание совместимости со всеми современными версиями.

[English documentation](README.md) · [PHP-клиенты](https://github.com/localzet/xray-grpc-php)

## Структура и происхождение

`src/` содержит схемы Xray. `php/` — отдельный репозиторий/submodule с генерируемыми сообщениями PHP и gRPC-клиентами. Имена пакетов ссылаются на [XTLS/Xray-core](https://github.com/XTLS/Xray-core). Точный исходный релиз исторического снимка не записан: перед обновлением схем и заявлением совместимости его необходимо установить. При импорте новых схем сохраняйте исходные уведомления и применимые лицензии.

Исторический бинарник `.grpc/grpc_php_plugin` не имеет зафиксированной версии и происхождения сборки; скрипт больше не выбирает его автоматически. Проверенный плагин необходимо задавать явно. Нативный исполняемый файл в Git не является переносимой инструментальной цепочкой.

## Проверка и генерация

Скрипт требует protoc 25.8, работает из любой папки и прекращает выполнение при ошибке. CI проверяет синтаксис/импорты и генерацию сообщений PHP во временную папку, не перезаписывая репозиторий клиентов.

```sh
bash compile_proto.sh --check
PHP_OUT_DIR=/tmp/xray-php-generated bash compile_proto.sh --php-only
GRPC_PHP_PLUGIN=/absolute/path/to/grpc_php_plugin bash compile_proto.sh
```

`PROTOC` позволяет задать абсолютный путь компилятора. Источник — [официальный релиз v25.8](https://github.com/protocolbuffers/protobuf/releases/tag/v25.8). SHA-256 Linux x86_64 архива в CI: `f7873a2b57811575c661faffa847e0e9b1bb06a1aea5021eccb05e8c04b260d5`.

Для полной генерации клиентов нужен PHP gRPC-плагин из явно выбранной ревизии официального grpc. Зафиксируйте её и проверьте разницу генерируемых файлов до коммита. Это остаётся условием выпуска. Ручные обёртки не следует перезаписывать генератором. Сначала публикуется и проверяется коммит клиентов, затем меняется указатель submodule родительского репозитория.

## Граница эксплуатации

API управления Xray выполняет привилегированные операции. Открывайте его локально либо через аутентифицированный приватный транспорт и правила доступа. Потребителю PHP нужны `ext-grpc` и зависимости Composer; эксплуатационная проверка должна использовать настоящую поддерживаемую версию Xray, ошибочные статусы и тайм-ауты. Незавершённая локальная обёртка API не является проверенным релизом генерируемых клиентов. Этот CI не публикует Packagist и не развёртывает сервер.
